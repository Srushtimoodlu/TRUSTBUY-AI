# TRUSTBUY-AI
"An AI-powered platform for detecting and identifying dark patterns on websites to promote transparency and protect users from deceptive design practices."


## Backend Setup

### 1. Clone the repository

```bash
git clone https://github.com/Srushtimoodlu/TRUSTBUY-AI.git
cd TRUSTBUY-AI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment (Windows)

```powershell
.\venv\Scripts\activate
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Start the Flask backend

```bash
python -m backend.app
```

### 6. Open the backend

http://127.0.0.1:5000/

Health check:

http://127.0.0.1:5000/health
